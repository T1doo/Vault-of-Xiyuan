## 实施步骤

- [ ] 固定学生、教师、clean/plus 来源版本，建立四个隔离环境与独立 LIBERO 配置；先检查官方依赖和真实 CLI。
- [ ] 下载并核验 pi0_fast_base、FAST tokenizer、Spatial 原始演示及七维所需官方资源，不下载额外研究套件。
- [ ] 联合盘点训练—开发—最终底层初态、官方配置、唯一 reset 和生效随机性；任何训练重划在 norm/标注/缓存前决定。
- [ ] 验证两视图、状态/动作语义与时间同步；每任务专家回放，完成动作正逆变换与 FAST 回环。
- [ ] 实现项目 S 共用严格解码/溢出检查、冻结白名单和模型入口确定性预处理，验证冻结叶子不变、LoRA 更新。

- [ ] 按主文档执行小样本与 1k—3k 开发训练、保存恢复和多检查点闭环；记录真实 profile，不使用最终单元调参。
