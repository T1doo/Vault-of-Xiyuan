### 2. A：方向草案与首批真实试标（T03）

- [x] 固定第一轮训练轨迹清单：每任务约5条完整train轨迹，以稳定规则预先选择并记录ID、选择规则和hash，不从val抽样或重分数据。
- [x] 形成`direction_protocol.json`草案，分别定义在线角色解析、离线实例绑定、方向轴/边界及当前抓持判据。

  槽位按`manipulated_object`、`placement_target`排序，最多两个，保留颜色、左右、between等完整指代；关系参照物不自动占第二槽位。在线问题只依赖当前文本；GT实例绑定只给既定问题生成离线监督，不能反写问题。绑定依据演示任务的指代和实例证据建立，演示内目标身份保持不变；逐状态更新位置和当前抓持状态，不因对象移动每帧重新选择“当前最左”等实例。

  以夹爪为原点、固定机器人基座轴计算`R_base_from_world @ (p_object_world-p_eef_world)`，六方向取绝对值主轴。对象root body原点、`gripper0_grip_site`、固定基座轴和米制单位已作为项目标签约定采用；原记录与恢复点的0.676 mm差异保留，不硬修为零。当前双侧fingerpad对已绑定操作对象的接触作为`grasped`候选代理，优先于六方向边界，但不证明稳定承载或未来成功；身份/状态不确定时仍invalid。2 mm死区已采用用于F2，非最优性结论；正式协议待G2冻结。

- [x] 验证逐样本恢复`states[i+1]`后提取对象/夹爪位姿及当前抓持信息的真实接口，与原`obs[i]`对应；不得自由开环重放后取漂移位姿，也不得执行未来动作辅助判断。
- [x] 先生成30—50个有代表性的帧级问题材料（已生成40题；阶段仅选例代理，真实阶段复核仍待完成），在10任务、两角色、消歧表达及接近/抓持转换/放置等主要维度各取代表，尽量包含边界/无效例，不要求几十题实现完整交叉覆盖；记录选例方法与未覆盖项。

  每例展示sample_id、原始双视图、原指令、问题槽位/完整指代、离线对象绑定、夹爪/对象位置、基座轴、方向结果和不确定原因。阶段判定来源属于离线QC元数据；无法可靠判阶段须保留unknown，不强填。输出逐题审核表，审核者和结论初始留空；自动生成材料不算人工审核。

- [x] 汇总试标总体及任务×阶段×槽位覆盖、有效类别和invalid原因；分开报告槽位有效率与整样本可用率。覆盖和类别分布从固定试标轨迹的标签全集统计，不从有意富集边界/invalid的代表例估计；全量统计从相应全量划分产生，QC一致率只描述已审集合。

  任一必需槽位不可信时，SA/SAB整个样本采用action-only打包，不插假答案后仅屏蔽CE。多数类规则最终由train有效标签决定，并固定并列处理；子集统计明确标“试标”，不冒充全train多数类。关键阶段系统性缺标须分析，不以总体覆盖掩盖，不自动改类别权重/重采样/删除类别。

- [x] 在保留原始草稿的前提下，按采用的“接触优先、再做六方向”的顺序，对固定50条train轨迹的12,548个槽位执行一次2 mm候选死区统计；输出候选标签、槽位/样本覆盖、任务/角色/接触分布和全部受影响题键。该统计为候选规则审阅材料，所有记录仍`approved_for_training=false`，不从结果调阈值或补造类别。

- [x] 以`sample_id + slot_index + direction-candidate-20260911-v2`建立300题内部质检准备包：保留既有40题并关联新规则，从剩余固定试标槽位按任务/角色/接触/候选状态稳定分层补260题；准备包只生成索引和审核空栏，不预填PASS，不把准备包计为人工QC。
